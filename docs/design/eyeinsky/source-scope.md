## Requisitos de producción

El build público funciona como archivos estáticos HTTPS con salida del navegador a `https://earthquake.usgs.gov/earthquakes/feed/v1.0/summary/all_day.geojson`. Cesium Workers, Assets, Widgets, JS/CSS y `/identity` deben servirse en el mismo origen. USGS debe permitir CORS; su disponibilidad no la garantiza esta aplicación. La cartografía local funciona sin acceso externo.

`vite preview` sólo sirve archivos del build. **No implementa** los servicios `/api/*` del backend upstream. Un despliegue que habilite proveedores adicionales necesita implementar/configurar los módulos `server/providers/`, aplicar términos/autorizaciones, cache/CORS/límites y reauditar esa superficie. Los endpoints de sesión de voz y key-setup no pertenecen al build público. No desplegar el servidor de desarrollo a Internet.

Las operaciones son `localStorage` por origen. Cambiar host, puerto o navegador cambia el almacén. Cuota/denegación/corrupción se informan; la recuperación borra sólo `eyeinsky.operations.v1` con confirmación. El fragmento compartido contiene vista pública, no notas ni nombre. Borrar los datos del navegador elimina las operaciones; la aplicación no funciona como respaldo remoto.
